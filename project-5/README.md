# Task Manager with File I/O

## Cognifyz Software Development Internship - Task 5

### Description
This project is an enhanced version of the Task Manager application developed in Java. It performs CRUD (Create, Read, Update, Delete) operations and stores task data permanently using file handling (File I/O). Tasks are automatically saved to a text file and loaded again when the program is restarted.

### Objective
To implement file handling in Java by storing task information in a text file, allowing data to persist even after the application is closed.

### Features
- Add a new task
- View all tasks
- Update an existing task
- Delete a task
- Save tasks to `tasks.txt`
- Load saved tasks automatically when the program starts
- Menu-driven console application

### Files
- `Task.java` – Defines the Task object.
- `TaskManager.java` – Contains the CRUD operations and file handling logic.
- `tasks.txt` – Stores task data permanently.

### How to Run
1. Open the project in VS Code.
2. Compile both Java files.
3. Run `TaskManager.java`.
4. Choose the required operation from the menu.
5. Tasks will be automatically saved to `tasks.txt`.
