# Task Manager (CRUD)

## Cognifyz Software Development Internship - Task 3

### Description
This project is a console-based Task Manager developed in Java. It allows users to perform CRUD (Create, Read, Update, Delete) operations on tasks using an ArrayList.

### Objective
To understand and implement CRUD operations using Java collections and object-oriented programming concepts.

### Features
- Add a new task
- View all tasks
- Update an existing task
- Delete a task
- Menu-driven console interface

### Technologies Used
- Java
- VS Code

### Concepts Used
- Classes and Objects
- ArrayList
- Methods
- Loops
- Switch Case
- Scanner Class

### How to Run
1. Open the project in VS Code.
2. Compile the Java files.
3. Run `TaskManager.java`.
4. Select menu options to perform CRUD operations.

### Learning Outcomes
- Object-Oriented Programming
- CRUD Operations
- Collection Framework (ArrayList)
- User Input Handling
