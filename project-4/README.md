# Temperature Converter

## Cognifyz Software Development Internship - Task 4

### Description
This project is a Java console application that converts temperatures between Celsius and Fahrenheit based on the user's choice.

### Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Menu-driven interface
- User input using Scanner

### Technologies Used
- Java
- VS Code

### Concepts Used
- Switch Case
- Scanner
- Arithmetic Operators
- Variables

### How to Run
1. Open the project in VS Code.
2. Compile and run `TemperatureConverter.java`.
3. Choose the conversion type.
4. Enter the temperature.
5. View the converted result.
