# Software Development Internship

## Overview

This repository contains the projects completed as part of my **Software Development Internship** at **Cognifyz Technologies**. The projects were developed using Java to strengthen problem-solving, programming fundamentals, object-oriented programming, file handling, and console application development.

## Internship Details

- **Organization:** Cognifyz Technologies
- **Role:** Software Development Intern
- **Duration:** July 2026 – August 2026
- **Mode:** Remote

## Projects

### Task 1 – Quiz Game
A console-based quiz application that uses conditional statements to ask multiple-choice questions, evaluate user responses, and display the final score.

### Task 2 – Number Pattern Generator
A Java application that generates different number patterns using nested loops based on user input.

### Task 3 – Task Manager (CRUD)
A menu-driven console application that performs Create, Read, Update, and Delete (CRUD) operations using Java collections.

### Task 4 – Temperature Converter
A Java console application that converts temperatures between Celsius and Fahrenheit based on the user's choice.

### Task 5 – Task Manager with File I/O
An enhanced version of the CRUD Task Manager that stores task data permanently using Java File I/O, allowing tasks to be saved and loaded automatically.
